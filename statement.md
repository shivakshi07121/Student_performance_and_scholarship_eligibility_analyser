Student Performance & Scholarship Analyzer

1. Project Title

Student Performance & Scholarship Analyzer

2. Problem Statement

The Student Performance & Scholarship Analyzer is a Python-based project designed to analyze a student's academic performance and determine their scholarship eligibility.

The system collects student details, subject-wise marks, attendance percentage, and annual family income. It then calculates the student's total marks, percentage, average marks, grade, pass/fail result, highest-scoring subject, and lowest-scoring subject.

Based on the student's academic performance, attendance, and family income, the system also checks scholarship eligibility and generates a final report.

3. Objectives

- To store and process student information.
- To calculate total marks and percentage.
- To calculate the average marks.
- To determine the student's grade.
- To check whether the student has passed or failed.
- To identify the highest and lowest scoring subjects.
- To validate attendance and family income inputs.
- To check scholarship eligibility.
- To generate a final student performance report.

4. Inputs

The program takes the following inputs:

1. Student name
2. Roll number
3. Branch
4. Semester
5. Subject-wise marks
6. Attendance percentage
7. Annual family income

The program also validates attendance and income values before processing them.

5. Processing

The project performs the following operations:

- Calculates total marks.
- Calculates percentage.
- Calculates average marks.
- Determines the grade.
- Checks pass/fail status.
- Finds the highest-scoring subject.
- Finds the lowest-scoring subject.
- Validates attendance.
- Validates family income.
- Checks scholarship eligibility.
- Generates the final report.

6. Main Modules

The project is divided into different Python modules:

- "student.py" – collects student details.
- "marks.py" – collects subject-wise marks.
- "performance.py" – performs academic calculations and analysis.
- "scholarship.py" – checks scholarship eligibility.
- "validation.py" – validates attendance and income.
- "report.py" – generates the final report.
- "main.py" – controls the overall execution of the project.

7. Output

The program displays a final report containing the student's:

- Personal details
- Subject marks
- Total marks
- Percentage
- Average
- Grade
- Pass/Fail result
- Highest-scoring subject
- Lowest-scoring subject
- Attendance
- Family income
- Scholarship eligibility status
- Reason for scholarship eligibility/ineligibility

8. Technologies Used

- Programming Language: Python
- File Format: ".py", ".md"
- Concepts Used: Functions, modules, loops, conditional statements, exception handling, input validation

9. Conclusion

The Student Performance & Scholarship Analyzer provides a structured way to analyze student academic performance and scholarship eligibility. It combines multiple modules to collect, validate, process, and present student information in the form of a final report.
